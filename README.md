# 浙智研析 · ZheZhi YanXi

**v1.0.2｜面向高校研究与管理工作的本地智能研究工作台**

把分散的政策文件、研究文献和项目材料连接起来，完成资料发现、项目梳理、关系探索与辅助分析。以 DeepSeek 为大模型底座，浏览器提供交互界面，Python 服务在本机运行。

## 功能

| 模块 | 可以做什么 |
| --- | --- |
| 资料检索 | 通过分步问题明确主题，检索文献、政策与新闻；核验正文、展示关键词和相关度，按相关度、日期或影响力排序；右侧阅读正文、总结与引用关系。 |
| 项目梳理 | 汇总会议纪要、工作报告、表格与图片材料，生成可追溯的整理报告；点击关键结论查看原文依据，并继续提问。 |
| 知识图谱 | 导入文件或文件夹，生成引用与提及关系图；调整拓展层数，拖动节点、缩放、分层或邻居高亮，查看来源与可用下载链接。 |
| 辅助决策 | 选择分析类型、背景模板与报告结构，结合材料生成专题分析或报告，标明依据并提出后续问题。 |
| 文献推荐 | 结合资料库和近期使用记录发现相关内容；启动后后台准备，支持缓存、首次导读、左右浏览与换批。 |
| 资料问答 | 使用自己配置的 DeepSeek 模型对话，可引用本地资料片段，查看来源并切换模型。 |

界面包含动态首页、六个功能入口、可收起导航、目录选择器及适配窄屏的布局。

## 快速开始

### 双击启动

下载并解压完整仓库后双击 `start.cmd`。启动器依次检测项目虚拟环境、当前用户的 Codex Python、Python 启动器和常见 Python 安装位置。它与 `启动.ps1` 使用同一套启动流程。

第一次启动若缺少依赖，会自动下载到本项目 `.deps` 目录，可能需要几分钟，请保持网络连接和终端窗口开启。后续依赖完整时直接启动。若没有兼容的 Python，请先安装64位 Python 3.12，再次双击；当前发布包不包含 Python 本体。

排查启动环境可运行 `start.cmd --check`，只检查或准备依赖，不启动网页。

### 运行环境

- Windows 10/11，64 位。
- 推荐 **Python 3.12（64 位）**。当前依赖版本按此环境准备，不建议直接使用更新的 Python 大版本安装固定 OCR 依赖。
- 可访问 DeepSeek 和外部检索来源的网络；自己的 DeepSeek API Key。
- 不需要 Node.js，也不需要前端构建。

下载仓库 ZIP 并解压，或通过 Git 克隆。进入包含 `app.py` 的项目目录，在 PowerShell 中执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

浏览器会自动打开本地页面。完成首次安装后，双击 **`start.cmd`** 即可启动；关闭服务终端会停止应用。也可使用 `启动.ps1`，它优先选择项目虚拟环境，并兼容原开发环境的 Python。

当前为本地 Python 应用，**不是独立 EXE 安装包，也不是可直接部署到 GitHub Pages 的静态网站**。服务只监听 `127.0.0.1`，使用动态端口；如需手动打开页面，查看终端显示的地址。

### 首次配置

1. 在“模型与资料设置”中选择 DeepSeek 官方、浙大比赛专用网关或自定义兼容接口，填写对应平台的 API Key 并保存。
2. 测试配置并获取可用模型，选择账户实际支持的模型。默认模型名可修改，以接口返回结果为准。
3. 选择资料总目录；可另行设置本地政策目录，目录中可以包含多级子文件夹。
4. 在资料问答模块点击“更新”读取资料；其他模块按各自流程选择材料或输入主题。
5. 如使用博查，在“扩展检索来源”中填写**独立的博查 API Key**；DeepSeek Key 不能用于博查。

DeepSeek 和可选第三方 API 的费用由相应账户承担。配置好模型后，启动时的推荐更新可能调用模型和检索服务；已有有效缓存会被复用。

### 浙大比赛网关与连接状态

选择“浙大比赛专用网关”会自动填写 `https://modelgateway.zju.edu.cn/v1/chat/completions` 和模型 `deepseek-v4-flash-780k-local`。填写比赛平台提供的密钥后保存。更换接口时需同时填写新平台密钥。密钥不会随代码上传。

配置区及侧栏显示连接测试状态：灰色为未测试或配置已修改，黄色为测试中，绿色为当前模型已成功响应，红色为测试失败。保存和启动后的连接检查会发送一条简短对话请求，可能产生少量调用费用。状态反映最近一次测试，并非持续网络监控。

部分网关不提供模型列表；只要实际对话测试成功，仍可手动填写模型使用。连接超时请检查网关地址、网络以及平台是否要求校园网或 VPN；401 表示该网关拒绝认证，需检查平台密钥是否匹配。

## 材料格式

| 类型 | 支持情况 |
| --- | --- |
| TXT / Markdown / CSV | 提取文本 |
| DOCX | 提取文档文字 |
| PDF | 提取文字型 PDF；扫描 PDF 建议先转为图片或文字型 PDF |
| XLSX / XLS | 提取工作表和单元格内容 |
| JPG / JPEG / PNG / BMP / WebP / TIFF | 本机 OCR，效果取决于清晰度和版面 |
| 旧版 DOC | 请先转换为 DOCX |

不同模块设有文件数量、大小和文本长度上限。例如图谱单次可选1–60份文件，每份不超过15 MB，拓展1–4层；全文不意味着原始文档的排版被完整复刻。

## 检索、引用与推荐说明

- 学术检索使用 Crossref、OpenAlex 等来源，政策和新闻结合公开网页、政府门户及可选博查检索；结果经过正文与主题相关性检查。
- **NSTL 尚未接入授权数据接口**：目前提供官方入口，后续需要机构授权与接口资料。
- 系统尽量扩大有效召回，但不保证任意主题都有20条以上真实结果。不会用不相关网页或虚构链接补足数量。
- 影响力结合可取得的被引信息或来源权威性提供参考，不同来源的指标不能直接等同于统一学术评价。
- 图谱区分“引用”和“原文提及”。它并不覆盖所有被引关系；外部数据库覆盖率、站点限制和原文证据都会影响结果。没有合法可用原文时，不能保证直接下载全文。
- 推荐优先使用资料库与近期主题；无个人记录时展示明确标识的公开资料导读，以数据治理作为可修改的初始方向。导读不冒充个性化结果，摘要节选也不等同于全文。
- 图谱解析和核验缓存可减少重复工作，首次生成仍受文件量、网络、模型响应和引用深度影响。

## 数据与隐私

- 原始材料只读。密钥通过 **Windows DPAPI 用户级加密**保存，不提交到仓库，也不会回传给网页；更换 Windows 用户后需要重新配置。
- 配置、上传副本、提取缓存、报告与推荐缓存等保存在 `%LOCALAPPDATA%\ZheZhiYanXi`。部分临时任务和对话只在内存中，刷新或重启后可能丢失。
- **本地运行不等于所有处理都离线。** 调用 DeepSeek 时，相关问题、对话上下文、选中材料片段或整理内容会发送至 DeepSeek；检索服务会接收主题词、标题或 DOI 等查询信息。
- 近期关注记录只在本机保存有限条目，用于推荐；API Key 不作为关注主题记录。
- 仓库默认排除资料库正文、环境目录、密钥配置、缓存、日志及本机调试产物。不要使用 `git add -f` 将私人材料加入公开仓库。
- 当前为单人本地工作台，没有多用户权限系统，不应直接对公网开放服务。

生成的分析和引用需结合原文核对，尤其是正式决策、政策效力及文献引用场景。

## 开发与验证

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -v
```

发布前72项后台测试通过；浏览器回归覆盖图谱高亮、材料选择、来源追溯、复制/导出、推荐预加载与翻页，以及桌面和窄屏布局。OCR 测试使用 Windows 微软雅黑字体；完整测试环境需要安装开发依赖。

```text
app.py                       本地 HTTP 服务、设置、密钥与问答
research.py / policies.py     检索、主题核验与政策处理
reader.py / citations.py      全文阅读与引用信息
knowledge.py                 多层关系图谱
fusion.py / decision.py       项目梳理与辅助决策
recommendations.py           推荐与缓存
interests.py                 本地关注主题记录
formats.py                   格式解析、OCR 与提取缓存
static/                      页面、样式、交互与图标
资料库/                      默认资料目录（私人内容不入库）
test_*.py                    自动化回归测试
CHANGELOG.md / VERSION       版本记录
```

若启动失败，优先检查 Python 版本与依赖安装；接口失败时检查网络、密钥、账户余额与可用模型。政策或新闻数量少可能源于来源限制，可调整主题、配置博查或加入本地资料。
